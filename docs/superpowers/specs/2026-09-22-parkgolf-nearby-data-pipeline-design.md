# 파크골프 주변 구장 데이터 전처리 파이프라인 — 설계 (서브프로젝트 A)

**목표.** 지역별로 형식이 제각각인 공공 CSV 17개를 정규화·필터링·지오코딩·중복제거해, 앱에 번들되는 **단일 JSON 자산**(`app/src/main/assets/parkgolf_venues.json`)을 생성하는 **재현 가능한 스크립트**를 만든다. 이 JSON 스키마가 서브프로젝트 B(앱 주변 구장 기능)의 계약이 된다.

이 서브프로젝트는 앱 코드(Kotlin)와 무관한 **빌드 타임 데이터 파이프라인**이다. 런타임은 오프라인 유지(생성된 JSON만 사용).

## 배경 / 입력
- 위치: `데이터/*.csv` (17개), 전부 **CP949** 인코딩.
- 스키마 5~6종: 표준데이터(좌표 O), 시도 "현황"(좌표 X, 주소만), 시설관리공단 시설정보, 생활체육시설(혼합) 등. 컬럼명·주소 컬럼 제각각.
- 좌표 결정: 좌표 없는 "현황" 구장(~170곳)은 **VWorld 지오코딩**으로 위·경도 보강(사용자 결정).
- 선택 동작(서브프로젝트 B): 주변 구장 선택 → **코스 마법사 프리필**(구장명·홀수 기본 파3). 따라서 이 데이터는 좌표·이름·홀수·주소가 핵심.

## 범위
- **포함**: CSV 읽기/인코딩 정규화, 스키마 라우팅, 비-파크골프 필터, 지오코딩(+캐시), 구장/코스 그룹핑, 중복제거, JSON 출력, 요약 리포트.
- **제외**: 앱 UI/위치 권한/거리 정렬(서브프로젝트 B). 홀별 파 데이터(원천에 없음 → 앱에서 기본 파3). 실시간 예약/운영시간 등 부가필드(스키마에 남기되 앱은 미사용).

## 도구/구성
- 언어: **Python 3**(표준 라이브러리 우선). 스크립트 `tools/build_venues.py` — 저장소에 커밋.
- 지오코딩: **VWorld Geocoder API**(도로명/지번). 키는 **환경변수 `VWORLD_KEY`**로 주입(커밋 금지).
- 캐시: `tools/geocode_cache.json`(주소→좌표) 커밋 → 재실행 시 API 재호출 최소화, 결정성 확보.
- 출력: `app/src/main/assets/parkgolf_venues.json`(커밋), 리포트는 stdout(총 구장 수, 소스별 건수, 지오코딩 성공/실패/캐시 히트, 제외 건수).

## 파이프라인 단계

### 1. 읽기·정규화
- 각 파일 CP949 → UTF-8. 헤더 공백 제거(`시 설 명`→`시설명`, `홀 수`→`홀수`, `규 모`→`규모`), 값 `strip()`.
- 숫자 정규화: 면적/홀수의 콤마 제거, 홀수·코스수 정수 파싱(실패 시 null).

### 2. 스키마 라우팅 → 공통 필드
각 원천 컬럼을 정규화 필드로 매핑(별칭 사전 기반):
- `name` ← `파크골프장명` | `시설명` | `시 설 명`
- `roadAddress` ← `소재지도로명주소`(있을 때)
- `jibunAddress` ← `소재지지번주소` | `소재지 지번주소` | `지번 주소` | `주소` | `위치`
- `lat`/`lng` ← `위도`/`경도`(있을 때)
- `holes` ← `홀수` | `홀 수` | `규모(홀)` (주의: `규모(미터제곱)`·`면적`은 **면적**이지 홀 아님)
- `courseCount` ← `코스수`(있을 때)
- `region` ← `시군`(있을 때) 또는 주소 접두에서 시/도·시군 파생
- `phone` ← `전화번호` | `연락처` | `운영기관 연락처` | `예약 문의 전화번호`(대표번호 우선)
- `operator` ← `운영기관` | `관리기관` | `운영기관명` | `운영기관명(관리기관명)`
- `source` ← 파일명 + `데이터기준일자`

### 3. 필터링(비-파크골프 제거)
- `제주특별자치도_골프장내장객현황*` → **파일 전체 제외**(월별 방문객 통계, 시설 데이터 아님).
- `대구광역시 북구_생활체육시설*` → `name` 또는 `보유시설`에 "파크골프" 포함 행만 채택(축구장·테니스장 등 제외).
- 그 외 파일도 방어적으로: `name`에 "파크골프"/"파크 골프"가 없고 파크골프 전용 파일이 아니면 경고 로그.

### 4. 지오코딩
- `lat`/`lng` 없는 행: `roadAddress`(우선) → 실패 시 `jibunAddress`로 VWorld 지오코딩.
- 캐시 우선 조회 → 미스만 API 호출(rate limit 준수, 실패 재시도 소수). 결과를 캐시에 기록.
- 성공: `coordSource="geocoded"`. 원천 좌표 사용 시 `coordSource="original"`. 실패: 좌표 null, `coordSource="none"`(데이터엔 남기되 B의 주변 목록에서는 제외).
- 주소 정제: "…일원", "…번지 일원", 말미 특수문자 제거 등 실패율 낮추는 최소 클린업.

### 5. 구장/코스 그룹핑
- **구장(place) 단위 그룹**: 같은 (정규화 이름 기저 + 좌표 근접 OR 동일 주소)이면 한 구장. 하위 `courses[]`.
- 거창 "…1구장"/"…2구장"(동일 이름줄기·좌표) → 한 구장, 코스 2개(각 18홀). 코스명은 원천의 구장 접미("1구장") 또는 기본 "A코스…".
- 현황의 "36홀"처럼 코스 구분 없음 → 코스 1개(holes=36). `courseCount`가 있고 총홀이 나눠지면 균등 분할 시도, 아니면 단일 코스.

### 6. 중복 제거(파일 간)
- 시도 "현황"과 시설관리공단 "표준"에 겹치는 구장: 좌표 근접(≈150m 이내) + 이름 유사도로 병합.
- 병합 우선순위: **표준데이터 > 시설정보 > 현황**(좌표·부대정보 풍부한 쪽 우선). 홀수/코스는 더 상세한 쪽 채택.

## 출력 스키마
`app/src/main/assets/parkgolf_venues.json` — 구장 배열:
```json
[
  {
    "name": "거창스포츠파크 파크골프장",
    "region": { "sido": "경상남도", "sigungu": "거창군" },
    "roadAddress": "경상남도 거창군 거창읍 심소정길 39-36",
    "jibunAddress": "경상남도 거창군 거창읍 양평리 1160",
    "lat": 35.69513581,
    "lng": 127.9263505,
    "coordSource": "original",
    "courses": [
      { "name": "1구장", "holes": 18 },
      { "name": "2구장", "holes": 18 }
    ],
    "phone": "055-940-8720",
    "operator": "경상남도 거창군 체육시설사업소",
    "source": "경상남도 거창군_파크골프장_20260811.csv"
  }
]
```
- 좌표 없는(`coordSource="none"`) 구장도 배열에 포함하되 `lat`/`lng`=null(B가 거리 계산에서 제외).
- 필드 부재 시 null. 홀수 미상이면 `holes`=null(B에서 기본값/입력 유도).

## 컴포넌트 경계(스크립트 내부)
- **로더**: 파일→정규화 dict 목록(인코딩·헤더·값 정규화). 순수 함수, 단위 테스트 대상.
- **매퍼**: 원천 컬럼→공통 필드(별칭 사전). 순수 함수, 테스트 대상.
- **필터**: 파크골프 판별. 순수 함수, 테스트 대상.
- **지오코더**: 주소→좌표(캐시 + VWorld). I/O 격리(캐시 주입 가능하게).
- **머저**: 그룹핑·중복제거. 순수 함수, 테스트 대상.
- **직렬화기**: 최종 JSON.

## 테스트
- 순수 로직(매퍼/필터/머저/값 정규화)에 대한 파이썬 단위 테스트(`tools/test_build_venues.py`): 헤더 별칭, 면적 vs 홀수 구분, 비-파크골프 제외(생활체육시설 축구장 제외·파크골프 채택, 제주 제외), 거창 멀티코스 그룹핑, 좌표 유무 분기, 중복 병합.
- 지오코더는 캐시/모의 주입으로 네트워크 없이 테스트(실제 호출은 실행 시).
- 실행 검증: 스크립트 실행 → 리포트 확인(총 구장 수·소스별·지오코딩 성공/실패), 출력 JSON 샘플 육안 확인(좌표 범위 33~39/124~132 유효성, 홀수/코스 sanity).

## 열린 사항(구현 시)
- **VWorld 키**: 사용자 제공(`VWORLD_KEY` 환경변수). 미제공 시 지오코딩 단계는 캐시만 사용/스킵하고 좌표 있는 데이터로 우선 진행 가능하도록.
- 지오코딩 실패율이 높으면 주소 정제 규칙 보강(반복).
